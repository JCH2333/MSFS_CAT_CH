# MSFS CAT CH

MSFS CAT CH 是一款免费的 Windows 桌面工具，用于安装、检查、更新和还原 Microsoft Flight Simulator 插件的简体中文补丁。软件无需账号、激活或自建服务，不收集遥测数据。

目前支持：

- GSX Pro 简体中文界面补丁；
- GSX 中文语音包；
- GSX 本体分流下载指引与 QQ 群分流入口。

软件和补丁均完全免费。软件作者为 B 站“一只剑齿虎呀”；GSX 中文语音包标注为网络作者，软件不提供该语音作者的外部跳转链接。

## 使用方法

1. 安装并打开 MSFS CAT CH，首次使用时阅读并同意用户协议与免费声明。
2. 软件会自动读取补丁目录，并尝试识别 Steam 版和微软商店版 MSFS 2020 / MSFS 2024 的常见插件目录。
3. 在“汉化补丁”页面选择 GSX Pro 简体中文补丁或 GSX 中文语音包，点击“安装补丁”。
4. 安装前软件会校验补丁包 SHA-256，并自动备份即将被替换的原始文件。
5. 如需恢复英文原始文件，点击补丁卡片中的“还原”。软件会保护安装后被用户自行修改的文件。

## GSX 中文语音包

语音包会自动寻找 FSDreamTeam Addon Manager 中包含 `couatl\GSX\sounds` 的目录。识别成功后可直接一键安装；识别失败时，可在“设置”页面手动选择该目录。

如在线下载缓慢，可下载官方提供的语音包离线 ZIP。在“汉化补丁”页面点击“导入离线包”，选择 ZIP 文件即可。请不要手动解压或直接覆盖文件，软件会先校验离线包完整性，再备份并安装。

## GSX 本体分流包

“分流包”页面提供 GSX 官方安装程序的下载入口。下载 `Addon_Manager_v4.0.15.exe` 后，关闭 Microsoft Flight Simulator，双击 EXE 并按官方安装向导完成 GSX 更新。

分流包只用于更新 GSX 本体，不包含汉化补丁、个人配置、日志或缓存。更新 GSX 后，请返回“汉化补丁”页面检查并按需重新安装对应补丁。

页面中的“MSFS CAT CH内测群”可打开 QQ 入群页面并显示二维码，用于获取分流信息和内测交流。

## 网络与补丁状态

软件启动或手动刷新时会先访问 Gitee 补丁目录；Gitee 不可用时再访问 GitHub，GitHub 超时后才会切换到国内镜像源。三个来源均不可用时，软件会使用最近一次有效的本地目录缓存。

- **未安装**：本机没有该补丁的安装记录。
- **已安装**：安装记录与已安装文件完整一致。
- **可更新**：补丁目录中存在更新的补丁版本。
- **需要修复**：已安装文件缺失或被修改。
- **本地版本较新**：本机补丁版本高于当前补丁目录版本。
