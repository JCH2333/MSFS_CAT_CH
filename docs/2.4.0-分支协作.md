## 合并流程（两条线都完成后）

1. 在 main：`git merge antipiracy-2.4.0`。
2. 重点解决上表共享文件的冲突；`package.json` 合并后统一为 version=2.4.0 + 完整 scripts（含 build-constants → integrity:manifest → electron-builder 顺序）+ electronFuses。
3. 跑全套 `npm test`（当前两线合计应 ≥400 用例）。
4. `npm run dist:win`（会先生成构建常量与完整性清单再打包——这是 antipiracy 线的强制管线，勿绕过）。
5. 静默覆盖安装给用户验收（本地版本号 2.4.0）。
6. 用户验收通过并明确授权后，按 OTA 流程发布 + 弹窗公告。
