# Domain Docs

This repository uses a single project context.

Before exploring or changing the project, read:

- `CONTEXT.md` at the repository root when it exists.
- Relevant architecture decisions under `docs/adr/` when they exist.

Use the exact domain terms defined in `CONTEXT.md` in issues, plans, implementation names, tests, and documentation. If a proposed change contradicts an existing architecture decision, identify that conflict explicitly before changing it.
