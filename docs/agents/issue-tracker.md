# Issue Tracker: GitHub

Tasks and PRDs for this repository live in GitHub Issues at `JCH2333/MSFS_CAT_CH`.
Use the `gh` CLI for issue operations and run it from this repository so it resolves the configured `origin` remote.

## Conventions

- Create: `gh issue create --title "..." --body "..."`
- Read: `gh issue view <number> --comments`
- List: `gh issue list --state open`
- Comment: `gh issue comment <number> --body "..."`
- Label: `gh issue edit <number> --add-label "..."`
- Close: `gh issue close <number> --comment "..."`

When a skill says to publish work to the issue tracker, create an issue in `JCH2333/MSFS_CAT_CH`.
